# Chrome Native UI Copilot — Judge Demo Script (60–90s)

Use Chrome Dev/Canary with Gemini Nano flags enabled. Load the extension (unpacked). Open a messy page or demo.html.

1) Hook — 5s
- Line: "This is Chrome’s native UI Copilot. It detects, fixes, and shares UI improvements — offline — in seconds."

2) Scan — 10s
- Click toolbar icon → "Scan Page".
- Narrate: "It finds accessibility, mobile and visual issues live."
- Point to the on-page badge: "X found · Y fixed".

3) Visualize + Click-to-fix — 10–15s
- Click "Visualize". Move cursor; click 2–3 broken spots.
- Line: "One click applies safe fixes. No code changes to the site."

4) Autopilot — 10s
- Toggle "Autopilot". Hover a section.
- Line: "A lightweight agent proposes and applies fixes as you work."

5) Export/Replay (Macros) — 10–15s
- Click "Export Fixes". Reload page. Click "Replay Fixes".
- Line: "Every change is a shareable macro. Reproducible and auditable."

6) DevTools: UI Copilot — 10–15s
- Open DevTools → UI Copilot → Auto-Fix All, show diffs.
- Line: "Developers get diffs and a batch-fix workflow."

7) DevTools: Design Tokens — 10–15s
- Open "Design Tokens" panel → Toggle Design System → set alias primary → --brand → Refresh; tweak token value.
- Line: "Align fixes to your design system via tokens and per-domain aliases."

8) Close — 5s
- Line: "From scan to shareable macro in under a minute — fully local, privacy-first."

Tips
- Keep pace brisk. Use zoom on badge and panels.
- Optional: show Lighthouse score bump in the Copilot panel.
