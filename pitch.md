UI Copilot — Chrome-Native UI Copilot (Winning Pitch)

What it is
- The first Chrome-native AI that detects, fixes, and shares UI improvements across any website — live, offline, and privacy-first.
- Runs on Gemini Nano with deep DevTools, context menu, and overlay integrations.

Breakthroughs (why this wins)
- Live UI Macros (Export/Replay): Every AI fix becomes a shareable macro. Export changes as JSON and replay them on any page/state — reproducible, auditable, hackathon-ready.
- Autopilot Agent: A lightweight on-page agent that inspects elements under the cursor and proposes safe fixes, optionally auto-applying them.
- Eyes Visual Inspector: Playful, memorable overlay that follows your cursor and lets you click-to-fix — delight meets real utility.
- DevTools Pro Panel: One-click Lighthouse bump, element-level analysis, batch fixes, and report export.

How to demo (3 steps in 60 seconds)
1) Open popup → Scan Page → watch issues populate with severity groups.
2) Toggle Visualize (Eyes) → click a few broken elements → instant fixes.
3) Export Fixes → reload page → Replay Fixes → show reproducible improvement.

Impact
- Accessibility: Raises WCAG compliance in seconds (contrast, ARIA, touch targets).
- Conversion: Improves CTA visibility, forms, and layout consistency automatically.
- Team workflow: Share fix macros between QA, design, and engineering — zero setup.
